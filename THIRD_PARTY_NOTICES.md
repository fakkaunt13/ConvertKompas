# Сторонние компоненты

Готовый EXE содержит Python 3.12, Tcl/Tk, comtypes 1.4.17 и загрузчик PyInstaller 6.22.3. Эти компоненты сохраняют собственные лицензии; лицензия MIT проекта ConvertKompas не заменяет их.

- [Python Software Foundation License](https://docs.python.org/3/license.html) — Python.
- [Tcl/Tk license](https://www.tcl-lang.org/software/tcltk/license.html) — графический интерфейс.
- [comtypes license](https://github.com/enthought/comtypes/blob/main/LICENSE.txt) — работа с COM.
- [PyInstaller licenses and bootloader exception](https://pyinstaller.org/en/stable/license.html) — сборка EXE.

КОМПАС-3D и его API не включены в программу. Для конвертации используется установленный на компьютере пользователя КОМПАС-3D v21.
