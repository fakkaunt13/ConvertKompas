# ConvertKompas

ConvertKompas сохраняет чертежи и модели из установленного **КОМПАС-3D v21** в форматах версий **16, 16.1, 17, 17.1, 18, 18.1, 19 и 20**. Поддерживаются `.cdw`, `.frw`, `.m3d`, `.a3d`, `.spw` и `.kdw`.

**[Скачать готовый ConvertKompas.exe](releases/latest)** · Windows x64

## Использование

1. Скачайте `ConvertKompas.exe` из последнего выпуска и запустите его. Устанавливать Python не нужно.
2. Выберите исходный файл или папку, папку результата и нужную версию КОМПАС.
3. Нажмите «Начать конвертацию». Исходные файлы сохраняются без изменений.

Для работы требуется установленный КОМПАС-3D v21. Сейчас программа ищет его файлы API в стандартной папке `C:\Program Files\ASCON\KOMPAS-3D v21\Bin`. Если выбранная папка результата пуста, она будет создана рядом с исходником под именем `КОМПАС <версия>`.

Если файл результата уже существует, новая копия получает дату: `Деталь (2026-09-30).m3d`. Следующие копии в тот же день получают номера: `Деталь (2026-09-30) (2).m3d` и далее.

**Личные папки не встроены в EXE.** Программа хранит выбор каждого пользователя отдельно в `%APPDATA%\ConvertKompas\settings.json`. Поэтому у другого пользователя при первом запуске поля пустые. Журнал последней обработки находится в `%TEMP%\ConvertKompas-last-run.log`.

## Сборка из исходного кода

На Windows x64 установите Python 3.12 с Tcl/Tk, затем выполните `./build.ps1` в PowerShell. Скрипт установит зависимости из `requirements-build.txt` и создаст один файл `dist\ConvertKompas.exe`. Исходный файл можно запустить командой `pythonw ConvertKompas.pyw` после установки `comtypes`.

ConvertKompas использует COM API установленного КОМПАС-3D. Файлы КОМПАС не входят в этот репозиторий и в готовый EXE.
